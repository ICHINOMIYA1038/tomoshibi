# TOMOSHIBI の照明演出

照明の演出案を作る前に、[調査と実装上の制約](../../../docs/stage-lighting-design-research.md)を読む。保存版「灯の帰路」は比較対象として残し、変更する場合は別の案を作る。

## 進め方

1. 台本やシーン情報から、観客に見せる人物・物、意図して隠す場所、時間や場所を示す光、切り替えのきっかけを記す。暗転・シルエットはその意図を明記する。
2. 役者の立ち位置と移動経路を確認し、必要な演技エリアを決める。顔を見る方向は客席視点を基準にする。
3. 顔を見せる前明かり、立体感を作る側光・逆光、重要な装置への光、効果の順に検討する。上方・左右約45°の前明かりは出発点であり、会場と演出に合わせて変える。狭いビーム一本を会話場面の顔明かりにしない。
4. 器具の実際のビーム角とフィールド角、照射距離、設置可能位置、16灯の上限を確かめる。動線の途中と演技エリアの境界にも光が届くようにする。
5. シーンごとに照明の役割と狙いを記録する。同じ舞台寸法・露出・環境光・客電・視点で完成図と切り替え途中を比較する。顔、重要な装置、背景との分離、影、光漏れを客席と俯瞰で確認する。
6. 測光値は光が届かない場所を見つける補助に使う。器具の直接光は描画と共通の設定で計算するが、影・客電・環境光・材質・露出は含まない。画面の明るさや実測 lux と同一視しない。暗いこと自体を失敗とせず、そのシーンの意図と照合する。

成果は、シーンごとの意図、器具と役割、固定した比較条件、確認できた見え方、残る問題を示す。器具配置の数値だけを複製して完成としない。上演会場での見え方は実際の仕込みと稽古で確かめる。
