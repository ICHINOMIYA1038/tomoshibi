# 『赤鬼』背景と地明かりの試作比較

実施日: 2026-11-08（JST）。[前の改訂案](../public/mock/demos/akaoni-wash.json)を残し、[照明試作案](../public/mock/demos/akaoni-study.json)を別に作った。変更対象は「花のしるし」だけ。**同じ 12 灯の点灯構成で、背景に並ぶ 3 つの山形を抑え、床の明るい部分を小さくできた。顔の照度も下がったため、見せ方は引き続き確認が必要。**

[前の画面](lighting-reviews/akaoni-hana-wash-audience.png)と[試作画面](lighting-reviews/akaoni-study-hana-audience.png)は、客席視点・露出 1.3・客電オフ・画質 High・画面幅 1440 px で撮影した。Chrome 156 の WebGL は SwiftShader で描画した。撮影画像の見た目では、背景の山形が消え、床中央の白っぽさも減った。一方、背景の上端には直線的な境界が見え、赤い布は客席視点で小さい。

## 変更した照明

- 海の面明かり 3 灯を、ホリゾント用の横に広い**試作配光**に置き換えた。灯具をホリゾントから離して上部から向け、3 灯を重ねた。
- 地明かり 4 灯を元の 70% に下げた。
- 人物用の前明かり 3 灯を狭い配光のプロファイルへ変更した。「花のしるし」での役者の立ち位置へ狙いを合わせた。

試作配光は円形スポットの角度減衰に、横方向へ広い矩形状の減衰を掛けたもの。３Ｄ描画には `SpotLight.map` を使い、照度計にも同じ減衰式を適用した。**実在のホリゾント灯具の測光データを再現した値ではない。** 実機の配光をうたう前に、IES 等の測光データと照合する。

## 「花のしるし」の直接光

同じ計算モデルを使い、床を 1 m 間隔で測った。[比較図](lighting-reviews/akaoni-study-floor-comparison.svg)は同じ色尺度を使う。

| 指標 | 前の改訂案 | 試作案 |
| --- | ---: | ---: |
| 床照度の 90 パーセンタイル | 57.6 lux | 25.6 lux |
| 床の最大点 | 67.4 lux | 33.1 lux |
| 隣接点の最大照度差 | 30.9 lux/m | 15.3 lux/m |
| 顔前面の照度：あの女 | 36.3 lux | 14.1 lux |
| 顔前面の照度：とんび | 19.4 lux | 16.7 lux |
| 顔前面の照度：ミズカネ | 30.7 lux | 19.5 lux |
| 顔前面の照度：赤鬼 | 49.7 lux | 23.4 lux |

数値は器具の直接光の推定値で、影、環境光、材質の反射、露出は含まない。試作背景灯の光束は仮置きの `5000 lm` で、配光マップによる光束の減少も校正していない。**表の lux は試作モデル内の比較値であり、実機の照度予測ではない。** [前の改訂案の診断 JSON](lighting-reviews/akaoni-wash-current-model-2026-11-08.json)と[試作案の診断 JSON](lighting-reviews/akaoni-study-2026-11-08.json)に計算条件と SHA-256 を保存した。

## 残る確認

全灯の静止画は確認した。前明かりを細くした影響で役者の移動中に顔が暗くならないか、場面転換の途中をまだ撮影していない。ほかの場面へ同じ調整を広げると顔が 2.9 lux まで暗くなる箇所があったため、今回は対象を「花のしるし」に限った。また、背景の右側が白く見える原因は、人物用の光の漏れとセットの反射を分けて確認する。背景灯の灯数を増やす判断は、この確認後に行う。
