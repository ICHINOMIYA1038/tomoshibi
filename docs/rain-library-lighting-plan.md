# 「雨を待つ図書室」照明演出メモ

「灯の帰路」とは別の演出デモ。机と本を物語の中心に置き、窓の冷たい光から夜明けの暖かい光へ移る。二人の会話では顔を見せ、雷鳴では顔を隠して窓と輪郭を見せる。

## 固定条件

- 舞台は現行モックの寸法を使用。客席視点、客電なし、環境光 0.08、露出 1.35、ヘイズ 0.23、ブルーム 0.32。
- 登場人物は司書と来訪者。装置は閲覧机、書架、雨の窓、返却された本。
- 器具は 9 灯。司書と来訪者の前明かり各 1 灯、本と机 1 灯、書架 1 灯、窓 1 灯、輪郭 2 灯、稲光 1 灯、夜明け 1 灯。
- 直接光の照度は顔の前面（高さ 1.35 m）と装置の表面で計算した。画面の明るさや実測値とは異なる。

## シーンの見せ方

| シーン | 見せる主体 | 光の変化 |
| --- | --- | --- |
| 閉館前 | 司書、本、書架 | 机を暖かく照らし、窓の青は弱く残す。 |
| 遅い来訪者 | 入ってくる来訪者と司書 | 上手の前明かりと輪郭を加える。 |
| 返された本 | 二人の顔と机上の本 | 本を強め、書架を暗くする。 |
| 雷鳴 | 窓と二人の輪郭 | 前明かりを消す。顔と書架は意図的に隠す。 |
| 余白の言葉 | 二人の顔と本 | 稲光を消し、暖色の机と前明かりを戻す。 |
| 雨がやむ | 机に寄る二人 | 窓の青を弱め、夜明けの逆光を加える。 |
| 本を持って出る | 本を持つ来訪者と司書 | 来訪者の移動先へ前明かりを向ける。 |
| 開館 | 司書と空いた机、書架 | 来訪者と本が退場し、朝の光を広げる。 |

## 確認結果

`node scripts/check-rain-library-plan.mjs` でシーンの保存・再読込、登退場、装置、照明の切り替えを確認した。通常の場面で舞台上にいる人物の顔は直接光 35 lux 以上、雷鳴の二人の顔は 0 lux、雷鳴の窓の前面は約 112 lux。3 組のシーン切り替えでは補間途中も検査した。これらの数値は、このデモの光の届き方を比べるための値であり、舞台照明の一般的な合格基準ではない。

稲光は現行の通し再生では 1.2 秒の共通補間で変化する。実際の稲光の短い閃光や、灯具ごとの時間差はまだ表現できない。客席と俯瞰での見え方は、ブラウザ上で最終確認する。
