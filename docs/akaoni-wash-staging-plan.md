# 『赤鬼』を題材にした浜辺の演出案・改訂

作成日: 2026-11-08（JST）。[改訂案のデモ](https://tomoshibi.gikyokutosyokan.com/mock/?demo=akaoni-wash)は、[元の５場面の案](https://tomoshibi.gikyokutosyokan.com/mock/?demo=akaoni)を残したまま、海の明かりと人物の距離を組み直した別案。３章・６場面、灯具14灯で構成する。[配置図](akaoni-wash-stage-map.svg)と[保存データ](../public/mock/demos/akaoni-wash.json)も用意した。

この案は作品から浜辺、洞窟、海へ向かう要素を選んだ TOMOSHIBI の非公式な試作で、上演台本や特定公演の舞台を再現していない。[NODA・MAP の公演紹介](https://www.nodamap.com/site/play/8)と[国際交流基金の作品紹介](https://performingarts.jpf.go.jp/article/6240/)を参照した。場面名、配置、きっかけ、照明キューは新しく作り、戯曲の台詞は収録していない。

## 六つの場面の焦点

| 章 | 場面 | 変化と見せる対象 |
| --- | --- | --- |
| 浜辺 | 波のあと | 三人と海の距離を見せる。地明かりは暖色、海は弱い青で分ける。 |
| 浜辺 | 浜に現れた影 | 赤鬼を海側に置き、人物が互いを意識する空間を作る。 |
| 浜辺 | 境目で足を止める | 足音が止まり、あの女だけが赤鬼へ一歩近づく。二人の間をまだ空け、赤い輪郭を弱める。 |
| 浜辺 | 花のしるし | 二人が中央へ進む。布だけを強く照らさず、二人の顔と赤い布の関係を見せる。 |
| 洞窟 | 洞窟で向き合う | 二人を内側、ほかの二人を外側に置き、岩の間の境界を使う。 |
| 海の向こう | 海の向こうへ | 舟に四人を寄せ、海側の輪郭へ焦点を移す。 |

新しい「境目で足を止める」は、登場から接近までを一度に進めず、二人の距離の変化を観客が追えるようにする場面。切り替えのきっかけを足音に置き、立ち位置と前明かりを同時に変える。

## 照明の改訂

- 地明かりのフレネル４灯は色をそろえ、舞台の演技エリアに重ねる。海の背景は同じ青の３灯で下手・中央・上手を受け持つ。
- 元の案で赤い布を強く照らした灯具を海側へ回す。「花のしるし」では床中央の直接光が約 93 lux から約 53 lux へ下がる。布は二人を見せる光の中に置く。
- 「境目で足を止める」と「花のしるし」では、とんびの顔を弱い補助灯で支える。「花のしるし」の顔前面は直接光の推定で約 10 lux から約 21 lux になる。焦点はあの女と赤鬼のままにする。

数値と設計上の理由は[光の重なりとリアルさのメモ](stage-lighting-overlap-and-realism.md)に記した。現時点で確認したのは保存データ、配置図、直接光の計算である。３Ｄ画面の客席視点と場面転換中の見え方は、実際にデモを開いて確認する必要がある。
