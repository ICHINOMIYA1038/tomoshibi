# 光だまりを抑えながら、灯具らしさを残す

調査・検討日: 2026-11-08（JST）。TOMOSHIBI の演出案で、床に丸い照射範囲が並んで見える問題を扱う。『赤鬼』を題材にした浜辺の案を実例とし、ほかの作品にも使える判断手順をまとめた。

**設計方針:** 柔らかい縁の光を複数の灯具で重ねる。人物の顔と動線を先に照らし、床の輪が目立つ灯具は狙いと光量を調整する。光は各灯具から計算し、影と距離減衰を残す。

## 重ねるのは実際の灯具から届く光

一つの灯具が床を照らすと、照射範囲に円形の跡ができる。演技エリアを複数の灯具で分担し、柔らかい縁を重ねれば、役者が移動する場所に暗い切れ目を作らずに済む。[ETC の照明計画](https://blog.etcconnect.com/stage-lighting-design-part-8)は演技エリア間の重なりを勧め、[ETC の器具解説](https://blog.etcconnect.com/stage-lighting-design-part-4)はフレネルの柔らかい縁が一般照明をなじませやすいと説明している。

ただし、均一な面を後から描き足すだけでは、灯具の位置、距離による減衰、人物や装置が落とす影、色の重なりが失われる。TOMOSHIBI では**各灯具から届く光を計算したうえで重ねる**。単独で見た輪郭を完全に消すことは目標にしない。見せたい人物と場所に自然に視線が向き、床の輪が演出の主役にならないことを目標にする。

| 見る点 | 調整の順序 |
| --- | --- |
| 演技エリア | 人物の立ち位置と動線を決め、必要な場所を灯具ごとに分担する。隣の灯具の縁が移動経路で重なるように狙いを調整する。 |
| 地明かり | 同じ役割の灯具は色をそろえる。床ではなく人物の高さも含めて狙い、重なった中央だけが明るくなりすぎないよう調光する。 |
| 顔と装置 | 顔を見せる光と、背景・装置を見せる光を分ける。弱い補助灯で顔を支えるときは、床への漏れも確認する。 |
| 演出効果 | 花や小道具に向けた灯具が床に大きな円を作るなら、狙い、角度、光量、遮光を見直す。暗く残す意図があれば記録する。 |
| 切り替え | 完成した各場面に加え、場面間の途中も見る。別の灯具が同時に強くなると、静止画にはない光だまりが出る。 |

[ETC のフレネル測光資料](https://www.etcconnect.com/workarea/DownloadAsset.aspx?id=10737460464)では、ビーム角は中心光度の 50%、フィールド角は 10% になる位置までの範囲を示す。ビーム角を「ここで光が急に消える線」とは扱えない。縁の柔らかさ、照射距離、器具の種類を一緒に見る。

## 『赤鬼』改訂案で試したこと

元の「花のしるし」は、赤い布用の１灯だけで床中央へ約 40 lux を加えていた。改訂案ではその灯具を海の面明かりへ回し、従来の海の１灯と追加の１灯を合わせて３灯で背景を受け持つ。地明かり４灯は同じ暖色のままにした。とんびの顔が暗くなる２場面だけ、弱い前明かりを追加した。

| 直接光の計算点 | 元の案 | 改訂案 |
| --- | ---: | ---: |
| 「花のしるし」の床中央 `(0, 0, -2) m` | 約 93 lux | 約 53 lux |
| 同場面のとんびの顔前面 | 約 10 lux | 約 21 lux |
| 海の面明かりだけを点けた背景中央 | 約 6.5 lux | 約 3.9 lux |
| 海の面明かりだけを点けた背景左右端 | ほぼ 0 lux | 左右とも約 2.0 lux |

海の３灯は中央を少し抑え、左右まで光を届ける設定にした。背景の数値を完全に均一にしたわけではない。新しい補助灯は床にも光を落とすため、客席視点で輪が目立つなら狙いと光量を再調整する。上表は器具の直接光の推定値であり、影、客電、環境光、材質の反射、露出を含まない。

## 描画の現状と、リアルさを上げる際の条件

現在の描画は three.js の `SpotLight` を灯具ごとに置き、照度計は共通の灯具設定から直接光を計算する。[three.js の SpotLight 仕様](https://threejs.org/docs/pages/SpotLight.html)に従って円錐角、縁のぼけ、距離減衰を設定している。床と人物への光は灯具ごとに加算される。一方、空中に見える半透明の光束は演出用の近似表現で、実際の霧や散乱の測定値ではない。

現在は器具の種類にかかわらず同じ `penumbra = 0.6` を使う。設定したビーム角と資料の 50% 境界が一致する保証もない。これはコードと器具資料を比べた推定で、画面上の輪郭を実測した結果ではない。今後、描画モデルを変更する際は器具ごとの測光曲線、ビーム角・フィールド角、遮光、影を扱い、**照度計と３Ｄ表示を同じ光分布で更新する**。先に色や床の面を塗りつぶして円だけを隠す変更は採用しない。

## デモを開いて確認すること

舞台寸法、客電、露出、カメラ位置を固定して、次を比較する。

1. 「境目で足を止める」と「花のしるし」で、とんびの顔が見えるか。補助灯の床への漏れが目立たないか。
2. 地明かりを１灯ずつ、次に全灯で点け、人物の移動経路と床の輪を比べる。
3. 海の３灯を単独と同時点灯で見て、背景の端の暗さと中央の重なりを比べる。
4. 場面転換の途中で、床の光だまりや顔の暗い瞬間が出ないか。

今回の配置図と直接光の計算では改善を確認したが、３Ｄ画面を客席視点で見比べる検証はまだ行えていない。
