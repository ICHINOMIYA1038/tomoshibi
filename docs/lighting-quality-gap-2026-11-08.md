# 『赤鬼』照明試作がまだ舞台らしく見えない理由

確認日: 2026-11-08（JST）。[照明試作案](akaoni-lighting-study-2026-11-08.md)は背景の山形と床照度差を抑えたが、舞台の見え方は十分ではない。原因は灯数だけではなく、**演出の焦点、舞台模型の材質、配光モデル、表示の評価方法**に分かれる。

## 画面と実装で確認したこと

| 見え方 | 実装上の原因 | 次に確かめること |
| --- | --- | --- |
| 背景が平らな青白い面に見える | ホリゾントは白い平面。新しい面明かりは手作りの矩形状配光で、実機の測光データは使っていない。 | 測光データのあるホリゾント灯具と、壁面の上下・左右の照度分布を照合する。 |
| 床が大きな一枚の明るい板に見える | 浜の地面は幅 10.5 m、奥行 5.2 m、厚さ 0.08 m の単色の箱。地明かり以外に人物用の灯具も床を照らす。 | 床の色・粗さ・形と、各灯単独の床への寄与を分けて見る。 |
| 人物と布に視線が集まらない | 人物は顔の造形がない単色メッシュ。赤い布は 0.8 × 0.5 m の薄い箱。客席視点ではどちらも小さい。 | 人物・布を読める大きさで撮り、配置・材質・狙いを決める。 |
| 数値の改善ほど見た目が改善しない | 照度計は器具からの直接光を計算し、影・環境光・材質の反射・露出を含まない。 | 同じ点の照度と画面の色・明るさを、条件を固定して比較する。 |
| 光と影が単純に見える | 現在の画面は three.js の `SpotLight` と標準 PBR 材質で描画する。残っている `RenderPipeline` は画面で使われていない。 | 影の柔らかさ、色管理、露出の校正を独立して確認する。 |

照明試作では「花のしるし」の床最大点が 67.4→33.1 lux に下がった一方、あの女の顔前面も 36.3→14.1 lux へ下がった。床を暗くすることだけでは、人物や赤い布をどう見せたいかは決まらない。

さらに、試作背景灯の光束は根拠のある実機値ではなく `5000 lm` と仮置きしている。円錐の立体角から光度を求めた後に、矩形状のマップで光を減らしているが、その減少分を光束へ反映していない。したがって、この案の lux は**試作モデル内の比較値**であり、実機の照度予測として扱えない。

## 次の順序

1. 「花のしるし」で最初に見る人物と赤い布を決め、客席視点の構図を固定する。
2. 床・人物・布を、照明の比較に耐える材質と形にする。ここを固定してから灯具を調整する。
3. 測光データに基づく背景灯の配光を採用し、照度計と３Ｄ描画で同じ分布を使う。
4. 顔・布・背景・床を別々に測り、場面転換と役者の移動中にも視線の焦点が保たれるか画面で確認する。

現行の試作配光は比較用として残す。本採用の判断は、実機データと画面の検証が揃ってから行う。
