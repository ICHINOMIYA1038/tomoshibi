# 地明かりと色を自然に見せるための舞台照明メモ

調査日: 2026-11-08（JST）。対象は TOMOSHIBI の演出デモ「雨を待つ図書室」。この文書では、役者が動く範囲を継続して見せる一般照明を「地明かり」と呼ぶ。

**結論:** 地明かりは床の均一な明るさより、演技エリアの人物を見せることを優先して組む。現行デモでは、床の照度をそろえるために広い光を 4 灯追加した。4 灯とも床へ向け、左右で色を変えている。

ユーザーには白色光と暖色光が混ざって見える。床にできる色の違う光だまりが、不自然さにつながっている可能性が高い。これはコードとユーザーの指摘からの推定であり、こちらでは画面を並べた視覚検証をまだ行っていない。

## 演技エリアと人物を基準に組む

| 基本 | 資料で確認した内容 | このデモへの意味 |
| --- | --- | --- |
| 演技エリアを先に決める | ETC は舞台を演技エリアに分け、顔明かりと逆光を組み、エリアの境目で役者が暗くならないよう少し重ねる方法を紹介している。約3 m 四方は一例で、舞台の大きさに合わせて変える。 | 床の全域より、司書・来訪者が立つ場所と入退場の経路を先に照らす。[ETC・照明計画](https://blog.etcconnect.com/stage-lighting-design-part-8) |
| 顔明かりと立体感を分ける | ETC は、顔を見せる前明かりの出発点に上方約45°を挙げる。側光や逆光は人物の形と背景からの分離に役立つ。角度は会場と装置に合わせて調整する。 | 床を明るくする灯具を増やす前に、二人の顔と輪郭の役割を確認する。[ETC・照射角度](https://blog.etcconnect.com/stage-lighting-design-part-5) |
| 広い光にも焦点が要る | ETC によると、フレネルは縁が柔らかく一般照明を重ねやすい。バンドアを付ければ、不要な場所への光漏れを抑えられる。 | 「広角にすれば自然」ではない。狙う位置、重なり、床や背景への漏れを調整する。[ETC・灯具の種類](https://blog.etcconnect.com/stage-lighting-design-part-4) |
| 明るさは視線誘導に使う | ETC は、観客の目が明るい場所へ向く一方、舞台全体を明るくしすぎると焦点を作りにくいと説明している。均一な一般照明と限定した光だまりは用途が違う。 | 本と人物を主役にするシーンで、床の隅まで同じ照度にする必要はない。[ETC・光の制御](https://blog.etcconnect.com/stage-lighting-design-part-3) |
| 色は人物・装置で確かめる | ETC は淡い色が顔の視認性と肌の見え方を保ちやすいと説明する。Rosco は演技エリアの前明かりを暖色・寒色・中性色に分け、側光や逆光の強めの色を別の役割として整理している。 | 基調色を決め、窓の青や机の暖色は動機のある場所へ限定する。衣装と装置の色も確認する。[ETC・色](https://blog.etcconnect.com/stage-lighting-design-part-6)、[Rosco・色フィルターガイド](https://au.rosco.com/sites/default/files/content/resource/2022-10/Rosco_Guide_to_Color_Filters_22.pdf) |
| キューの途中も設計する | ETC は、光の変化を瞬時にするか緩やかにするかで意味が変わり、クロスフェード中に視認性が落ちる場合もあると説明している。 | 雷鳴から会話、雨から夜明けへの途中で人物が見失われないか確かめる。[ETC・光の制御](https://blog.etcconnect.com/stage-lighting-design-part-3) |

暖色と寒色を左右から当てる「45°/45°」は、顔に陰影を作る実在の手法である。暖色と寒色の併用そのものを誤りとはしない。ただし、それは同じ人物を両側から形づくる話であり、床の左右に別の色を広く塗る必然性までは示していない。色の選択は作品の意図と実際の見え方で決める。[ETC・照射角度](https://blog.etcconnect.com/stage-lighting-design-part-5)、[Rosco・色フィルターガイド](https://au.rosco.com/sites/default/files/content/resource/2022-10/Rosco_Guide_to_Color_Filters_22.pdf)

## 現行デモは床を狙う4灯の色が異なる

以下は資料の一般論ではなく、現行コードを読んだ結果と、その結果からの推定である。コードのパスはこの作業ツリー内を示す。公開中の灯具設定は[デモの JSON](https://raw.githubusercontent.com/ICHINOMIYA1038/tomoshibi/main/public/mock/demos/rain-library.json)でも確認できる。

| コードで確認できる事実 | 見え方への推定 |
| --- | --- |
| 地明かりの 4 灯（`src/demo/createRainLibraryPlan.ts`）はフレネル 10 インチで、狙いの高さがすべて `0 m`。左右手前の設定色は `[1, 0.84, 0.7]` と `[0.76, 0.85, 1]`、舞台奥の 2 灯は別の青寄りの値。 | 床に光だまりを作りやすく、重なり方で床色が変わりうる。手前と奥で色の境目も生じうる。 |
| 照射モデル（`src/lighting/spotlightModel.ts`）ではフレネル 10 インチのビーム角 `32°` と `30°` が、フィールド角 `80°` と `75°` に広がる。 | 広い円錐光が床で重なり、シーンごとの調光によって光だまりの形が変わりうる。 |
| 検査（`scripts/check-rain-library-plan.mjs`）は床の左右手前を `24 lux` 以上、左右奥を `20 lux` 以上とし、中央と端の照度比も制限している。 | 人物の見え方より床の数値をそろえる方向へ調整しやすい。これらはデモ固有の回帰値で、舞台照明の基準ではない。 |
| 舞台床（`src/scene/Stage.tsx`）は暗い素材。描画側（`src/App.tsx`）には環境光と露出の設定がある。照度計は器具の直接光を計算する。 | 同じ床照度でも、画面の色・明るさ・影は数値だけでは判断できない。 |
| 描画側（`src/App.tsx`）は客電を消しても暖色の環境光と半球光を描く。 | 青寄りの地明かりを選んでも、画面には暖色の基礎光が重なる。照度計の直接光にはこの色が入らない。 |
| 色の計算（`src/lighting/spotlightModel.ts`）はタングステン器具の固定色温度 `3200 K` に指定 RGB を掛ける。色温度変換（`src/lighting/fixtureTypes.ts`）は簡易的な sRGB 近似だが、three.js の `Color` の RGB 成分は線形色空間として扱われる。 | 指定 RGB と表示色が直感的に対応しない可能性がある。実機の分光特性や、タングステンの減光による色変化も再現していない。[three.js・色管理](https://threejs.org/manual/pages/color-management.html)、[ETC・色](https://blog.etcconnect.com/stage-lighting-design-part-6) |
| デモはタングステンの前明かり（`src/demo/createRainLibraryPlan.ts`）に `whiteMix` を指定するが、照射モデル（`src/lighting/spotlightModel.ts`）のタングステン用処理はこの値を使わない。 | デモ側で「白を混ぜた」つもりでも、表示色は変わらない。色を調整するときは実際に反映される項目を確認する。 |

## 基調色をそろえ、役者の動線を照らす

1. **一つのシーンに一つの基調色を決める。** 閉館から会話までは淡い暖色寄りの中性色を基調にする。下手と上手の一般照明は同系色にそろえる。窓の青は窓と人物の輪郭、机の暖色は本と机に限定する。夜明けでは一般照明をまとめて朝の色へ移す。
2. **床ではなく演技エリアを狙う。** 司書の机まわり、来訪者の入口から机まで、二人が並ぶ位置を設定する。前明かりの狙いは顔・上半身を基準にし、床への光はその結果として確認する。
3. **暗い場所を残す。** 全域を同じ照度にしない。本と二人が主役のとき、舞台の端は暗くてもよい。ただし、役者の移動途中に意図しない暗い帯を作らない。
4. **役割ごとに灯具を分ける。** 一般照明、顔明かり、逆光、窓・机・書架、稲光を別々に調整する。地明かりの 4 灯を必要な演技エリアへ向け直し、灯数だけで改善を判断しない。現行アプリは最大 16 灯。
5. **色を数値だけで決めない。** 色空間と減光時の挙動を確認し、同じ視点・露出・客電・背景で比較画像を撮る。色の評価は人物の肌、衣装、本、床を並べて行う。

この方針は資料を踏まえた本デモ向けの提案であり、すべての作品で暖色と寒色の併用を避けるという規則ではない。

## 次の改訂で確認する画面

- 「閉館前」「返された本」「雨がやむ」「開館」を、客席と俯瞰の両視点で同じ露出に固定して比較する。
- 各シーンで、顔と本が主役に見えるか、床の色違いの光だまりや背景への漏れが視線を奪わないか確認する。
- 来訪者の入口から机までと、机から退場までの動線を確認する。雷鳴から「余白の言葉」への切り替え途中も確認する。
- 床の照度分布は、光の届かない場所を調べる補助値として残す。床の最低照度と均一性を合格条件にする現行の検査（`scripts/check-rain-library-plan.mjs`）は、演出意図に合わせて見直す。

ブラウザでの見た目と客席からの視線誘導は、今回の資料調査だけでは確認できない。次の改訂では画像を残して比較する。
