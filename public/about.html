TOMOSHIBI小屋は、ブラウザで使える舞台照明シミュレーターです

舞台照明のプランを 3D で組み立てて、本番の前に見え方を確かめられます。インストールは不要で、基本機能は無料です。戯曲図書館のサービスとして、演劇に関わる方に向けて作っています。

シミュレーターを開く

できること

  • 器具と役者を 3D の舞台に置き、ドラッグで位置や狙いを動かせます。
  • 物理ベースの描画で、光の減衰、影、面からの照り返しを確かめられます。
  • ヘイズやスモークの中で、ビームがどう見えるかを試せます。
  • 作った明かりをシーンとして保存し、共有 URL で渡せます。
  • スマートフォンでも操作できます。動作が重いときは、描画品質を下げられます。

収録している器具

PAR、フレネル、PC、Source Four などの在来器具と、Stairville、Chauvet、ADJ、ETC、Robe の LED 器具を収録しています。

本格的な用途にも対応しています

  • 照度（lux）や色温度の確認
  • IES、GDTF、GLTF ファイルの読み込み
  • WebSerial と Enttec OpenDMX を使った DMX 出力
  • VR ヘッドセットでの確認（WebXR）

料金

シミュレーター本体の機能は、Free プランですべて使えます。クラウドに保存できるシーンは 3 件までです。Pro プラン（月額 300 円、税込）では、この保存数の上限がなくなります。

はじめ方

  1. シミュレーターを開きます。
  2. 操作パネルの「器具」タブで器具を足し、「役者」タブで人を配置します。
  3. 3D の画面で器具を選び、矢印をドラッグして動かします。
  4. 「設定」の「シーン管理」から保存し、必要なら共有 URL を作ります。
